# Marketplace UI

Frontend for [alphagranny.com](https://alphagranny.com) — a Next.js 16 app with React 19, TypeScript, and Tailwind CSS 4.

Production: `https://alphagranny.com`

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses a local system font stack so production builds do not depend on fetching fonts from external providers.
